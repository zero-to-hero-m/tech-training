## 一、看板总体结构

看板遵循 **"检测—分析双闭环"** 的架构，整体划分为两条带（Band）+ 顶部标题栏 + 底部质量底线栏：

```
┌─────────────────────────────────────────────────────────┐
│ 顶部标题栏：系统在线 · 产线编号 · 状态总览 · 实时时钟        │
├─────────────────────────────────────────────────────────┤
│ 带 01 【检测端】 采集 → 识别 → 分拣剔除 → 质量追溯           │
│   ① 实时采集   ② 缺陷识别   ③ 分拣执行   ④ 良品率   ⑤ 设备状态 │
├─────────────────────────────────────────────────────────┤
│ 带 02 【分析端】 样本沉淀 → 缺陷分布 → 成因诊断 → 工艺 → 优化  │
│   ⑥ 质量指标   ⑦ 缺陷样本库  ⑧ 缺陷分布   ⑨ 诊断建议  ⑩ 工艺参数│
├─────────────────────────────────────────────────────────┤
│ 底部质量底线栏：0.1 毫米是底线 · GB/T 51117 · 中国制造精度     │
└─────────────────────────────────────────────────────────┘
```

- **布局**：1920×1080 固定画布，按窗口等比缩放适配；20 列 × 2 行的错落网格，重点区域（采集区）跨两行放大，其余为宽扁块与方块的混排。
- **视觉风格**：深空科技风 + 玻璃拟态（半透明磨砂、辉光边框、科技角标），SVG 线性图标，anime.js 负责面板错峰入场、数字滚动、进度条显现等动画。
- **数据架构**：事件驱动。检测模块广播 `DEFECT`（检出缺陷）/ `OK`（合格）事件，下游的计数、样本库、机械臂、良品率、诊断、分布图等订阅后联动更新——因此"一次检测"能同时驱动多个面板变化，形成闭环。

## 二、展示层功能（10 个面板）

这些面板始终运行，是"结果展示层"。改造后它们的数据来源从"自动播放"变成了"真实操作产生"，但外观不变。

### 带 01 · 检测端

| 序号 | 面板 | 功能说明 |
|---|---|---|
| ① | **实时采集区** | D435i 双模态成像。上半为 RGB 彩色画面（模拟工件在传送带上流动、焊缝纹理、相机视野锥与 15 FPS 标识），下半为深度图（热力渐变表示焊缝轮廓起伏，"近/远"标注）。采集区下方是交互控制台（见第四节）。**拍照后画面左下角显示最近抓拍缩略图**。 |
| ② | **缺陷识别区** | YOLO 检测可视化画面 + 三类缺陷统计卡：焊穿（红）、未焊透（橙）、咬边（蓝）。每类显示数量、较昨日趋势、以及占比进度条。默认基数 37 / 29 / 23，随真实检测结果增长。 |
| ③ | **分拣执行区** | 机械臂联动剔除的四阶段流水线动画：① 缺陷触发 → ② 机械臂定位 → ③ 抓取剔除 → ④ 废品区。带工件徽标（处理中）、机械臂 SVG 运动图、码垛/剔除累计计数。检测命中缺陷时自动播放。 |
| ④ | **良品率监控区** | 大号实时良品率数值（默认 96.3%）+ 涨跌标识、今日累计良品/总检数、良品率滚动曲线、最近工件追溯条目。可用按钮启动/暂停采样（见第五节 18）。 |
| ⑤ | **设备状态区** | 三张设备卡：西门子 S7-1200 PLC（扫描周期/通信/上线时长）、六轴机械臂（位姿/关节角度/轨迹模式）、IOT2050 边缘网关（吞吐/云端连接）。点击 PLC 卡可调出详细状态面板（见第五节 19）。 |

### 带 02 · 分析端

| 序号 | 面板 | 功能说明 |
|---|---|---|
| ⑥ | **质量指标区** | 准确率迭代曲线（82% → 94%，40+ 轮）+ 三张对比卡：AI 检测准确率 94%、人工目检 87%、迭代轮次 40+。可"放大查看"曲线与人机对比（见第五节 16/17）。 |
| ⑦ | **缺陷样本库** | 累计缺陷样本总量（默认 1,284）+ 最近 6 张缺陷缩略图（工件号/类型/置信度/时间叠加）。每次检出缺陷自动"截取当前帧"入库并触发数字跳动。 |
| ⑧ | **缺陷分布趋势** | 以工件序列为横轴、缺陷类型为泳道的散点分布图，鼠标悬停散点显示详情。**已修复悬停导致画布消失的问题**（缓存几何参数，鼠标移动不再清空画布）。 |
| ⑨ | **缺陷诊断 + 优化建议** | 上下堆叠两块：缺陷诊断给出成因定位（如电流过大/速度过慢），优化建议给出具体工艺调整方案。检测缺陷后自动显示对应类型的成因与建议。 |
| ⑩ | **工艺参数监控** | 焊接电流（185A）、电弧电压（22V）、焊接速度（8.5mm/s）三条实时参数条，缺陷出现时关联参数自动标记异常点。 |

## 三、交互控制功能总览

三批改造把看板从"被动演示动画"升级为"可操作的仿真控制台"。所有关键动作由人触发，**动作 → 画面变化 → 数据变化 → 日志留痕**的因果链清晰可复现。

| 批次 | 定位 | 入口 | 涵盖清单项 |
|---|---|---|---|
| 第一批 | 核心闭环（必做） | 采集区控制条 | 6/7/8/10/11/12/13 + 缺陷保存 + 日志抽屉 |
| 第二批 | 增强与实验 | 「⚙ 实验与执行中心」弹窗 | 9/14/15/16/17/18/19/20/21/22 |
| 第三批 | 多模态进阶 | 「🧠 多模态智能中心」弹窗 + 「✥ 布局编辑」 | 34/35/36/37/38 |

> 缺陷判定统一为**随机判定**：保留真实检测的不确定性，每次点击结果可能不同。判定遵循"先定真值、后检测读取"——工件出现时按概率确定是否缺陷，检测只是读取这个真值，因此结果可复现、可讲述。

## 四、第一批：核心操作闭环

入口：实时采集区下方的控制台，包含状态行 + 8 个操作按钮 + 进度条。

### 状态行
- **状态文本**：实时显示"模型就绪/未加载 · 传送带运行/停止 · 待检 N"。
- **待检徽标**：显示待检批次数量，有批次时高亮。

### 6. 启动/停止传送带
- **操作**：点 `▶ 启动传送带` / `⏸ 停止传送带`。
- **效果**：启动后工件在 RGB 与检测画面中流动；停止时工件驻留在检测位，便于对"当前这一件"做检测。
- **意义**：全流程总开关。采集与检测都以"有工件在流动或被驻留"为前提，能停才能检测当前帧。

### 7. D435i 拍照
- **操作**：点 `📷 拍照`。
- **效果**：定格当前一帧 → 画面闪一下快门 → 照片显示在 RGB 画面左下角 → 工件编号递增。
- **意义**：让"采集"从背景动画变成可讲述的具体动作——"我刚拍了这一张"。

### 8. 彩色图 / 深度图切换
- **操作**：点 `◧ 切到深度图` / `◨ 切到彩色图`（按钮文案随状态变化，激活时高亮）。
- **效果**：切换采集区主视图。彩色图看外观缺陷，深度图看焊缝轮廓起伏。
- **意义**：体现 D435i 的双模态成像能力。

### 10. 连续采集 ×10
- **操作**：先启动传送带，再点 `⏩ 连续采集×10`。
- **效果**：逐件抓取 10 件工件（带进度条 1/10 → 10/10），完成后形成"待检批次"，可看到"待检 10"徽标。
- **前置**：必须传送带运行（工件需流过采集位）。
- **意义**：模拟产线连续过件，同时为批量检测准备数据；强调"采集"与"检测"是两个独立步骤。

### 11. 加载 YOLO 模型
- **操作**：点 `⬇ 加载模型`。
- **效果**：分阶段进度（加载权重 → 初始化推理引擎）→ 按钮变为"✓ 模型已就绪"，检测类按钮随之解锁。
- **意义**：真实系统必须先加载模型才能检测。这个前置条件让流程有"上电—就绪"的真实语义。

### 12. 检测当前帧
- **操作**：模型就绪后点 `◎ 检测当前帧`。
- **效果**（随机判定）：
  - 命中缺陷 → 画检测框、触发机械臂剔除、缺陷入库（样本库+1）、日志+1、状态提示"已存证"。
  - 判定合格 → 提示"判定合格"，正常流转。
- **意义**：核心动作，把"拍照"和"判定"分开，让人亲手完成一次"采集 → 识别 → 处置"。

### 13. 批量检测并统计
- **操作**：有待检批次后点 `▦ 批量检测`。
- **效果**：逐张检测（带进度条），逐条出结果，完成后汇总"合格 N / 缺陷 N（焊穿X 未焊透Y 咬边Z）"。
- **意义**：体现工业吞吐能力，一次看到多条结果与分布。

### 缺陷日志抽屉
- **操作**：点 `📋 缺陷日志`，右侧滑出面板（`Esc` 或点遮罩关闭）。
- **功能**：
  - 按类型筛选（全部/焊穿/未焊透/咬边）。
  - 关键词搜索：支持缺陷类型、工件编号（`#W1342` 或 `1342`）、时间。
  - 每条记录显示工件号、类型、置信度、时间、处置状态。
- **意义**：日志是"按需查看"的数据视图，滑出式不占主画面，让"查记录"成为流程里明确可演示的动作。

## 五、第二批：实验与执行中心

入口：控制条 `⚙ 实验与执行中心` 按钮，打开集中弹窗。弹窗内部分区，部分功能可打开子弹窗（饼图/曲线/对比/PLC），子弹窗关闭后自动回到实验中心。

### 9. 相机曝光 / 增益调节
- **操作**：拖动"曝光"（0.4~1.8）和"增益"（0.5~2.0）滑块，或点"复位默认参数"。
- **效果**：实时影响 RGB 采集画面——曝光低变暗、高变亮；增益高会叠加噪点。
- **意义**：真实相机采集必须调参，过曝/欠曝会直接影响检测效果。有了它，"拍照"才像真的在调相机。

### 14. 置信度阈值实验
- **操作**：拖动"阈值"滑块（0.3~0.9）。
- **效果**：用一组固定样本按当前阈值重判，实时显示"检出 / 漏检 / 召回率"，并在阈值轴上画出样本点分布（实心红=检出，空心灰=漏检），下方给出结论（偏低激进 / 适中选择 / 偏高保守）。
- **注意**：此处改动会写入全局阈值，影响后续真实检测的判定——低于阈值的缺陷按"漏检合格放行"。
- **意义**：YOLO 检测最核心的实验，直观展示 precision/recall 权衡，答辩中很有说服力。

### 15. 缺陷占比饼图
- **操作**：点 `◕ 缺陷占比饼图`（或刷新按钮）。
- **效果**：Canvas 绘制环形饼图，展示焊穿/未焊透/咬边各自比例，带图例与数值。
- **意义**：进度条擅长比较大小，饼图擅长表达"整体构成"，两者互补。

### 16. 准确率迭代曲线（放大查看）
- **操作**：点 `📈 准确率曲线`。
- **效果**：子弹窗放大显示 82%→94% 的迭代曲线。
- **意义**：把常驻的小图变成一个"主动触发查看"的动作，讲解时可以说"我们来看准确率曲线"。

### 17. 人机对比
- **操作**：点 `⚖ 人机对比`。
- **效果**：多维度对比 AI vs 人工——检测准确率（94% vs 87%）、检测速度（92 vs 45 件/min）、漏检率（3% vs 11%，越低越好）、连续工作能力（100% vs 68%）。
- **意义**：体现 AI 价值最直接的证据，值得单独展示。

### 18. 良品率监控启停
- **操作**：点 `⏸ 暂停良品率监控` / `▶ 启动良品率监控`。
- **效果**：控制良品率曲线的采样；暂停时面板标签变"已暂停"。
- **意义**：让监控成为可控动作而非背景动画，与传送带启停呼应。

### 19. PLC 状态面板
- **操作**：点 `🔌 PLC 状态`，或直接点击设备区的 PLC 卡。
- **效果**：子弹窗显示型号 S7-1200、运行状态 RUN、扫描周期、上线时长、CPU 负载、通信状态，以及数字量输入 DI / 输出 DO 的点位表。
- **意义**：把"看状态"深化为"查面板"，体现工业现场的可观测性。

### 20. 机械臂码垛
- **操作**：点 `🦾 机械臂码垛`。
- **效果**：机械臂走四阶段"码垛中"动画，完成后提示"良品已码垛入库（第 N 件演示）"，码垛计数+1。
- **意义**：真实产线机械臂既剔除缺陷品也码放良品，补上码垛动作让执行环节完整。

### 21. 气缸剔除演示
- **操作**：点 `💨 气缸剔除演示`。
- **效果**：分拣区气缸机构高亮，气缸杆快速推出再收回（约 1.2 秒），提示"缺陷件已剔除"。
- **意义**：机械臂抓取与气缸推出是产线最常见的两种剔除方式，补上它让"剔除"环节有对比和选择。

### 22. 设备报警处置
- **触发方式**：
  - 手动：点 `🚨 模拟设备报警`。
  - 自动：连续检出 3 件缺陷时系统自动报警。
- **效果**：顶部滑出红色报警条，显示报警原因（需人工确认复位）；点 `确认并复位` 或 `✓ 报警复位` 后恢复，顶部状态总览回到"正常运行"。
- **意义**：闭环必须有"异常处理"这一环，否则系统只能演示顺利情况；有报警与处置才像真实运行的设备。

## 六、第三批：多模态智能中心

入口：控制条 `🧠 多模态智能中心`（5 个 Tab）+ `✥ 布局编辑`。定位为**演示级模拟**——在单机看板内做出可信的交互效果，不接外部硬件或服务。

### Tab 1 · 34 语音查询
- **操作**：点麦克风 `🎤 开始说话` 说出查询（如"查一下焊穿缺陷"）；无麦克风时点"模拟一次语音查询"。
- **效果**：
  - 支持 Web Speech API 的浏览器真实识别语音；无权限/不支持时自动降级为预设语句模拟。
  - 从自然语言中提取关键词（"查一下焊穿缺陷" → "焊穿"），显示"识别结果 → 检索词"。
  - 自动跳转到"跨模态检索"Tab 并带出结果。
- **意义**：语音是自然交互的前沿形态，演示"能听懂人话"比点按钮更有记忆点；语音落点是文本检索，体现跨模态协同。

### Tab 2 · 35 跨模态检索
- **操作**：输入关键词（缺陷类型 / 工件编号 / 时间 / 置信度）回车或点检索；也可用快捷按钮（焊穿/未焊透/咬边）。
- **效果**：命中记录以"缩略图 + 工件号 + 类型 + 置信度 + 时间"列表展示，并显示命中条数；点任意记录 → 进入四模态联动。
- **匹配能力**：中文名、英文 type、工件编号（`W1338`/`1338`）、时间片段（如 `14:45`）、置信度数值均可命中。
- **意义**：文本是最通用的检索模态，也是语音识别结果的落点；"跨模态"体现在一次检索同时带出文字记录和对应图像。

### Tab 3 · 36 四模态联动
- **操作**：在左侧图像墙点选任意缺陷照片。
- **效果**：右侧四部分协同更新——
  - **① 图像模态**：放大的缺陷缩略图 + 工件标识。
  - **② 语音描述**：自然语言描述（"工件 #W1342 检出焊穿，置信度 0.93，建议…"），可点 `🔊 播报` 用 speechSynthesis 朗读（不支持时显示文字）。
  - **③ 文本记录**：结构化的工件编号/类型/时间/处置状态。
  - **④ 数据 / 统计**：检测置信度、同类缺陷数、类型占比三个仪表 + 模型/阈值说明。
- **意义**：多模态的核心卖点——不是四种模态各干各的，而是"从一个模态切入，其他模态跟着动"。

### Tab 4 · 37 看板 DIY 布局
- **操作**：点 `✥ 进入布局编辑`（或控制条的 `✥ 布局编辑`）进入编辑态，底部出现工具条。
- **编辑能力**：
  - **拖拽交换**：按住任意面板拖到另一面板上，两者位置互换。
  - **尺寸调整**：面板右上角"大 / 中 / 小"按钮——大=占满两行，中=标准，小=复位。
  - **保存布局**：写入本机 localStorage，刷新后仍生效。
  - **恢复默认**：清除自定义布局。
  - **完成**：退出编辑态（`Esc` 也可退出）。
- **意义**：真实看板按岗位定制（质检员关注缺陷、班组长关注良品率），DIY 布局体现"以人为中心"的可配置性。

### Tab 5 · 38 双屏联动
- **操作**：点 `🖥 打开联动大屏` 新开一个窗口（URL 带 `?role=screen`），两窗并排；状态区显示"已连接 N 块联动屏幕"（心跳保活）。
- **效果**：
  - 大屏端自动进入"联动大屏模式"：隐藏控制条、顶部显示"联动大屏 · 实时接收主控数据"标识。
  - 主控端选中缺陷 / 切换视图 / 触发报警 / 检测命中时，通过 BroadcastChannel 实时同步；大屏自动弹出四模态联动视图，并顶部闪过同步提示。
  - 点 `🔄 立即推送当前状态` 可手动同步一次。
- **意义**：真实车间是"操作屏 + 大屏"分离的，双屏联动贴近部署形态，适合答辩现场一大一小两块屏展示。
- **依赖**：需较新版本 Edge/Chrome 支持 BroadcastChannel；不支持时 Tab 内给出提示。

## 八、完整操作闭环（串讲脚本）

把主干串起来，可以手动走完一整遍，每一步都有可见反馈：

```
① 加载模型 ──▶ 模型就绪，检测按钮解锁
② 启动传送带 ──▶ 工件开始流动
③ [可选] 实验中心调曝光/增益 ──▶ 采集画面明暗/噪点变化
④ 拍照 或 连续采集×10 ──▶ 抓拍照片 / 形成待检批次
⑤ [可选] 切深度图看焊缝轮廓
⑥ 检测当前帧 或 批量检测 ──▶ 随机判定
      ├─ 缺陷 ──▶ 画检测框 + 机械臂剔除/气缸剔除 + 缺陷入库 + 日志+1 + 诊断建议
      └─ 合格 ──▶ 机械臂码垛 + 良品数+1
⑦ 查看结果 ──▶ 饼图 / 准确率曲线 / 人机对比 / PLC 状态 / 分布趋势
⑧ 异常时 ──▶ 设备报警 → 人工确认复位
⑨ 追溯 ──▶ 缺陷日志抽屉（类型/编号/时间检索）
⑩ 多模态 ──▶ 语音查询 → 跨模态检索 → 四模态联动 → 看板 DIY → 双屏联动
```

任意一次缺陷都能从画面追溯回日志条目，形成"采集—识别—处置—分析—追溯"的完整证据链。

## 九、状态机与前置依赖

| 状态 | 含义 | 对操作的影响 |
|---|---|---|
| **模型未加载** | 初始态 | 检测当前帧 / 批量检测按钮禁用，提示"请先加载模型" |
| **模型就绪** | 加载模型后 | 检测类操作解锁 |
| **传送带运行** | 启动后 | 工件流动，可连续采集 |
| **传送带停止** | 初始/停止后 | 工件驻留，可检测当前帧；连续采集不可用 |
| **有待检批次** | 连续采集后 | 批量检测按钮解锁 |
| **采集中 / 检测中** | 批量操作进行中 | 按钮临时禁用，显示进度条，防重复点击 |
| **报警态** | 连续缺陷/手动触发 | 顶部报警条显示，需确认复位后恢复 |
| **布局编辑态** | 进入 DIY 后 | 面板可拖拽、显示尺寸条，底部工具条出现 |

**关键依赖链**：`加载模型 → 检测`；`传送带运行 → 连续采集 → 待检批次 → 批量检测`；`待检批次` 来自连续采集，采集与检测是两个独立阶段。

## 十、演示级模拟的能力边界

为便于理解与答辩，明确哪些是"真实逻辑"、哪些是"演示级模拟"：

- **真实逻辑（事件驱动闭环）**：一次检测通过事件总线同时驱动计数、样本库、机械臂、良品率、诊断、分布图、日志等多个面板联动；操作有前置条件、有状态、有留痕、有反馈。
- **演示级模拟**：
  - 缺陷判定为**随机**（按概率定真值），非真实 AI 推理。
  - 相机画面、深度图、工件流动、机械臂动作均为 Canvas/SVG 模拟绘制，非真实 D435i/PLC 硬件数据。
  - 语音识别依赖浏览器 Web Speech API，不支持时降级为预设语句模拟；语音播报依赖 speechSynthesis。
  - 双屏联通用 BroadcastChannel 在本机多窗口间同步，非跨网络/跨设备。
  - DIY 布局保存在本机浏览器 localStorage，非云端账户同步。
  - 检索数据来自本次会话累积的缺陷记录 + 预填历史样本。

> 这种定位的价值：在不依赖额外硬件或外部服务的前提下，完整呈现工业质检系统的交互逻辑与数据闭环，可直接用于演示与讲解。
