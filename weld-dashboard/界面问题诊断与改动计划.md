## 一、你指出的三个问题（P0，必须修）

### 1. 折线图 Y 轴顶部「100%」显示成「00%」

**现象**：良品率监控区、质量指标区两张折线图的 Y 轴，最上面一格本应是 `100%`，实际只显示 `00%`，开头的 `1` 不见了。

**证据**：放大图中良品率区 Y 轴自上而下为 `00% / 95% / 90% / 85% / 80%`；质量指标区同样为 `00% / 95% …`。

**根因**：两处都用「右对齐 + 贴着左内边距」画刻度文字：
- `src/yield-chart.js:68` → `ctx.fillText(v + '%', pad.left - 4, y + 3)`，`pad.left = 34`
- `src/accuracy-chart.js:49` → 同样写法，`pad.left = 35`

15px 字体下 `100%` 宽约 36px，右边缘落在 `pad.left - 4 = 30`，左边缘算出来约为 `-6`，被画布左边界裁掉，正好吃掉开头的 `1`。低刻度 `95%` 等字数少所以没事。

**拟改动**：把两张图的 `pad.left` 从 34/35 加大到 **46**，刻度文字 x 相应改为 `pad.left - 6`（保证左边缘 > 0）；同时把刻度字号从 15px 收到 13px，整体更精致。曲线绘图区 `cw` 会随之略缩，同步生效，不影响数据映射。

### 2. 柱状图盖住缺陷卡片数据

**现象**：缺陷识别区右侧，红色/橙色/蓝色三根柱子的数字 `37 / 29 / 23` 直接压在「焊穿 / 未焊透 / 咬边」三张卡片上，第三张「咬边 23」几乎被完全遮挡。

**证据**：DOM 实测坐标——柱状图数字 `top = 245~290`，而卡片 2/3 的范围是 `top = 213~307`，完全重叠。

**根因**：这个面板在高 212px 的宽扁块里，右侧 `.defect-log` 是竖向 flex 容器，里面塞了「3 张卡片横排 + 柱状图 + 日志列表」三层；`.bar-num` 又用 `top:-15px` 往上冒，空间不够就压到了卡片上。此外柱状图的数字和卡片数字本就是同一组数据（37/29/23），信息重复。

**拟改动（推荐方案）**：**去掉重复的柱状图**，右侧改为「3 张卡片纵排」——每张卡片显示缺陷名、数量、趋势，并在卡片底部加一条细进度条表示占比。这样信息不重复、零遮挡，212px 高度刚好放 3 张。
> 备选：保留柱状图，但把它移到左侧检测画面正下方横跨，卡片纵排靠右。若你更想保留柱状图视觉效果，我按备选做。

### 3. 检测画面背景堆叠一堆无关文字

**现象**：缺陷识别区左侧的 YOLO 检测画面里，顶部同时出现两三行标题类文字，底部挤着一行 `OK / NG / MODEL / FPS / CONF THR` 调试信息，还有工件编号、置信度标签混在一起，看起来像「背景里有很多无关文字」。

**证据**：放大图可见画面上方 `YOLO DETECTION ZONE`（青色）+ `D435i -> YOLO`（黑底）+ HTML 胶囊 `YOLO DETECTION` 三层叠加；底部 `OK:12 | NG:5 MODEL: YOLOv8 | FPS:15 | CONF THR:0.50` 全部糊成一团。画布实际只有 325×142px，塞不下这么多文字。

**根因**：`src/defect-detect.js` 在同一画布上重复绘制了标题与调试 HUD：
- `:112` `fillText('YOLO DETECTION ZONE', …)` 与 HTML `index.html:76` 的 `.cam-label`「YOLO DETECTION」语义重复
- `:122` `fillText('D435i -> YOLO', …)` 又是一层标题
- `:321-332` 底部状态条画了 OK/NG/MODEL/FPS/CONF THR 一整行

**拟改动**：
- 删除画布内的 `YOLO DETECTION ZONE` 与 `D435i -> YOLO` 两处标题，标题只保留 HTML 那一枚胶囊
- 底部状态条只保留 `OK: n / NG: n` 且缩小字号，`MODEL/FPS/CONF THR` 这行调试文字删除（面板标题「YOLO·三类缺陷」已表达模型信息）
- 画面内的 `OK 0.94` 置信度标签保留（属于有效检测结果），工件编号 `#Wxxxx` 从画面移除（下方追溯徽标已有）
- 检测区「检测区」文字与方块略有重叠，一并微调Y坐标

## 二、检索中发现的其他问题（P1，建议一起修）

### 4. 折线图的文字标注压在曲线上

- **良品率区**：`src/yield-chart.js:87` 的「目标 95%」画在 95% 参考线上，和曲线末端叠在一起（放大图里文字被青色曲线穿过）。
- **质量指标区**：`src/accuracy-chart.js:72` 的「人工目检 87%」画在 87% 基准线上，与绿色上升曲线交叉。
- **拟改动**：两处标注都加一个半透明底色小胶囊并上移 3~5px，或移到网格右上角留白处，避免与曲线重叠。

### 5. 缺陷分布趋势区 X 轴文字重叠成「工件编号200」

**现象**：X 轴最左侧「工件编号 →」和第一个刻度「1200」叠在一起，显示成 `工件编号200`（见放大图）。另外「焊穿集中区 1200~1252」这行注释压在红色散点上。

**根因**：`src/defect-distribution.js:106` 把「工件编号 →」画在 `pad.left`，而 `:97` 的 1200 刻度用 `xOf(1200)` 也在同一 x 位置。
**拟改动**：把「工件编号 →」移到 X 轴右端（`pad.left + cw`）并右对齐；集中区注释从散点上方移到图表右上角留白处，或加半透明底。

### 6. 深度图右侧色标「远 / 近」文字被裁切

**现象**：实时采集区 DEPTH MAP 右侧彩色标尺顶端的「近」字只剩半截贴在边缘。
**根因**：`src/depth-camera.js:112-113` 用 `fillText('近', w - 5, 10)` 且文字非右对齐，右边缘超出画布。
**拟改动**：改为 `textAlign='right'` 后画在 `w - 4`，或把色标整体左移留出文字空间。

### 7. 顶部 Logo 的「W」轻微裁切

**现象**：header 左上角 Logo 里的字母宽度超出容器约 4px，边缘被切。
**证据**：DOM 扫描 `header-logo` 的 `scrollWidth=40 > clientWidth=36`。
**拟改动**：给 Logo 容器加 2~4px 内边距或缩小字号/图标。
